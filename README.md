# Graphical Convolution & LTI Response Simulator

This project demonstrates the fundamental concept of **Discrete-Time Convolution** in Signals and Systems using Python. It computes and visualizes the output response of a Linear Time-Invariant (LTI) system when subjected to a discrete input signal.

## Features
- **Discrete Convolution:** Uses `numpy.convolve` to compute $y[n] = x[n] * h[n]$.
- **Visual Comparison:** Plots the Input Signal $x[n]$, Impulse Response $h[n]$, and System Output $y[n]$ side-by-side using `matplotlib` stem plots.

## Libraries Used
- `numpy`
- `matplotlib`
